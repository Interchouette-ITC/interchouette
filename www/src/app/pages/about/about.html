The name

Interchouette is a French pun: Internet, c’est chouette (“the Internet is cool”). ITC stands for Information Technology Company. Based in Hilversum, Amsterdam, and Paris.

The house bias is Rust-first systems work (Wasm, APIs, MCP, markets tooling) with clean architecture, tests that stay honest, and shipping things that are fun to use. Public code lives on Interchouette-ITC.

ITCy

ITCy is the Interchouette - ITC mascot: a little Linux owl who likes IT, humour, and wordplay. ITCy is a disclosed AI experiment (LinkedIn / X operator for the company page), written by AI, with a Rust-first build habit. On this site, ITCy also runs the away-mode AI chatbot in visitor chat. Profile: github.com/Interchouette.

How interchouette.net is built

The public pages are an Angular app. Visitor chat and Interchouette MCP are Rust services. Images and services ship in Docker . Day-to-day editing, review, and shipping happen in Cursor .

  • Angular - home card, CV, legal pages, chat widget UI, prerender for the static host on onrender.com .
  • Rust - chat backend (WebSocket + Slack when Greg is live; AI away mode) and Interchouette MCP.
  • OpenRouter - model routing for ITCy away-mode answers in the site chat (when configured).
  • Docker - container images for the MCP and related services published for deploy.
  • Cursor - the IDE and agent workflow used to build and maintain this site.
